# JLL Case Study — Charity Donor Outreach Skill

Submission for the JLL AI Product Lead case study.

The brief had two parts: (1) assess a draft "charity-donor-outreach" AI skill and describe improvements and their impact, and (2) rewrite the skill to implement them.

- **assessment/JLL_Case_Study.pdf** — Part 1: the written assessment (23 findings across trust, determinism, and operational control)
- **skill/charity-donor-outreach/SKILL.md** — Part 2: the rewritten skill
- **skill/charity-donor-outreach/scripts/calculate_asks.py** — the deterministic ask calculator the rewritten skill invokes, implementing the core recommendation of separating calculation from language generation

All donor data referenced is mocked per the exercise instructions. The charity (ASPCA) is real; no real donor data is involved.
